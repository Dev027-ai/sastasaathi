# Branded medicine comparison catalogue

This catalogue is generated by `scripts/build_branded_medicine_catalog.py` and the GitHub Actions workflow `.github/workflows/build-branded-medicine-catalog.yml`.

## Source and interpretation

- Branded catalogue source: [Indian Medicine Dataset](https://github.com/junioralive/Indian-Medicine-Dataset), published as a CSV with product name, listed price, manufacturer, pack size and composition. Its README describes a dataset of 253,973 products.
- Source licence: MIT. See [upstream LICENSE](https://github.com/junioralive/Indian-Medicine-Dataset/blob/main/LICENSE). Retain attribution when redistributing derived data.
- Jan Aushadhi reference: `data/jan_aushadhi_extracted.csv`, extracted from the supplied price-list PDF. Its publication date is not verified.

## Matching safeguards

The builder attempts to match active ingredients and strengths, dosage form, and release type before including a comparison. It calculates per-unit differences only where pack quantities can be parsed. It does not infer clinical equivalence.

**Important:** the upstream price is labelled as a source-listed price and is not independently confirmed as the current printed MRP. The generated CSV should not be used as a substitute for checking current package labels or official price notifications. The script deliberately fails rather than fabricating a 500-row result if fewer than 500 eligible exact matches are found.

## Generate or refresh

Open the repository's **Actions** tab, choose **Build branded medicine comparison CSV**, and select **Run workflow**. The job downloads the source CSV, builds `data/branded_medicines_500.csv`, and commits it if successful. It is also scheduled to refresh monthly.

Review the Actions run and inspect the generated rows before using price comparisons in the app.
