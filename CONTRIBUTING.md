# Contributing

1. Open an issue or describe the user problem before making a broad change.
2. Keep pull requests focused and commits small, with clear messages.
3. Test mobile layout, keyboard navigation, search, savings arithmetic, and offline behavior.
4. Preserve the source CSV and `data_review_status` field; do not present unverified prices as current.
5. Do not add medicine substitutions, dosages, or clinical advice generated by an AI model.
6. Document any new dataset, API, model, or library and its licence/source.
